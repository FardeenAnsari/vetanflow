# VetanFlow Frontend

React + Vite + TypeScript dashboard for the India-first payroll system.

## Scripts

```sh
npm run dev --workspace frontend
npm run typecheck --workspace frontend
npm run build --workspace frontend
```

## UI Direction

- Operational payroll dashboard, not a marketing landing page.
- Dense but readable cards, tables, and workflow status.
- Tailwind CSS with accessible shadcn/Radix-inspired component patterns.
- Lucide icons only; no emoji as structural UI.
